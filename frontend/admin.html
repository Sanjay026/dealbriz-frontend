EMI Coverage Areas

Where EMI is offered. Rules are checked most-specific-first: pincode → district → state, so you can enable a whole state and exclude individual districts from it, or re-enable a single pincode inside an excluded district.

With no rules, EMI is unavailable everywhere. Buyers still see EMI badges on listings, but get an explanation when they tap "Buy with EMI". The global switch in Site Settings overrides all of this.

Roles & Access

Choose which parts of the admin panel each role can open, and what they can do there. Changes apply the next time that user loads a page.

Superadmin is fixed and can't be edited. If it could, a superadmin could remove their own ability to assign roles and permanently lock everyone out of administration.

Feature Switches

These change what the public site offers. Only superadmins can save changes.

EMI & Financing
Controls whether EMI is advertised site-wide: the homepage EMI section and calculator, the EMI nav link, EMI badges on listings, and the EMI Partners page.

This is a visibility switch, not a kill switch. Whether EMI actually works is decided by EMI Coverage:
• Off — EMI is hidden from everyone except users whose location is covered. Use this to pilot a region quietly.
• On — EMI is advertised everywhere, and still only usable in covered areas.

To stop EMI completely, remove every coverage area. With no coverage rules, EMI is unavailable regardless of this switch, and the server rejects any application submitted through a stale page or a direct request.
EMI Status page
Shows or hides EMI Status in the user menu, where buyers track their EMI applications. Off hides the link and the page for everyone. Applications are not touched, and staff still see them under EMI Applications.

Existing EMI applications are never deleted by this switch. Staff can still review them under EMI Applications, and turning the switch back on restores everything exactly as it was.
